# Münzwurf-Simulation

Dieses Python-Projekt simuliert zufällige Münzwürfe und stellt die Ergebnisse grafisch dar.

## Funktionen
- Simulation beliebig vieler Würfe
- Auswertung von Kopf/Zahl-Häufigkeiten
- Darstellung der Ergebnisse mit Matplotlib
- Eingabe der Wurfanzahl über Tkinter

## Installation

```bash
pip install numpy matplotlib
